## Unreleased

- README: the Mermaid pipeline now marks the exam moment with its own node (stadium shape + amber color, in the legend too) between printing and scanning; the "Components" table lists the software bricks (CLI, Typst generation, OpenCV OMR, FastAPI review UI, stdlib-CSV grading) instead of the commands. Sphinx renders Mermaid diagrams larger (`mermaid_init_config`: fontSize 20px, node/rank spacing 70).
- Docs: the API reference is now one page per module (`docs/source/api/{cli,generate,omr,web,grading}.md`) with a sub-menu under "API" in the sidebar (`api.md` holds the hidden toctree).
- README: Components table reduced to 2 columns (component / implementation), OMR acronym spelled out (Optical Mark Recognition, in the table and the features list); Mermaid command nodes now slightly rounded (parenthesis shape), the exam moment keeps the stadium shape, legend sub-graph removed (the shapes/colors are self-explanatory in context).
- README: Features rewritten user-need oriented (less technical), with a first bullet insisting that everything is 100% local (no cloud, no account, no upload).
- README: the Mermaid pipeline now shows the manual grading of open questions as its own human step (stadium + amber, like the exam moment) between the review UI and `corrections.json`; the Features bullet mentions grading open questions manually.
- Workflow clarified: open questions are graded ON PAPER before scanning (the grader blackens one grade box `0..max_points` = a fraction of the max per open question; the OMR reads it, ungraded → `needs_review`); the review UI is for doubtful cases and overrides. Updated: README pipeline (manual-grading step moved between the exam and the scan) + Features, `quickstart.md`, `runbook.md` (new "Manual grading (on paper)" section), `SCOPE.md`.
- Sources aligned with "review UI = doubtful cases only": `list_copies` docstring states only non-`ok` copies need review (corrections stay possible as overrides); stale "not graded yet" wording in `read_bubbles` → "not blackened on paper". README Mermaid manual-grading node label shortened.
- Docs: the README is embedded in the Sphinx homepage again (`index.md` includes it; the `readme.md` sub-page tried in between is removed).
- Template: open-question grade boxes are now in a gray grader area (AMC-style, visually distinct from the student bubbles), the "Grade:" label is removed, and boxes are labeled with letters A, B, C… instead of numbers (value = letter index, kept in the `#metadata` for the OMR). Docs updated (quickstart/runbook/SCOPE/README), preview image regenerated.
