# Changelog

## Unreleased

- Coverage badge + published report: `genbadge` + `defusedxml` in the `test` group, `[tool.coverage.report] fail_under = 90`; pre-push hooks `coverage` (`pytest --cov --cov-report=xml:coverage.xml --cov-fail-under=90`) and `coverage-badge` (`genbadge coverage` → committed `assets/coverage.svg`, hook fails if the badge is stale); CI `coverage` job replays both hooks (with the typst binary installed); README badge links to the HTML report published by the `pages` workflow at `coverage html -d docs/build/coverage` → `https://boileaum.github.io/mini-amc/coverage/`. Current coverage: 93.59%.
- D6: torture tests + OMR hardening — 11 new tests in `tests/test_torture.py` (shared helpers moved to `tests/synth.py`): noise, under/over-exposure, blur, 0.5x/0.35x low-DPI, JPEG q70, sideways page, cut marker → `unread`, damaged QR → `unread`, mixed batch (`ok` / `needs_review` / `unread`). Fixes: `unwarp` rolls the destination quad when the detected marker quad is wider than tall (sideways pages no longer anisotropically stretched); `read_qr` tries all 4 rotations and keeps the one whose QR is geometrically top-right (an upside-down QR also decodes, so position disambiguates), with a regex-parse helper; `detect_markers` picks the candidate closest to each expected corner (guard 25% of the diagonal) instead of requiring exactly 4 components. Real validation: 40-question copy, 7 pages photographed with perspective jitter + blur + noise + JPEG q75 → copy `ok`, 40/40 answers matching `answers.json`, 0 `needs_review`.
- Docs homepage `docs/source/index.md` now includes `README.md` (`eval-rst` + `.. include::` with `:parser: myst_parser.sphinx_`), build stays warning-free with `-W`.
- CI split into one job per pre-commit hook (`pre-commit run <id> --all-files`, one step per id): hygiene, ruff, types (ty), docstrings (pydoclint), docs (sphinx-build), tests (pytest pre-push).
- New `.github/workflows/pages.yml`: publish Sphinx docs to GitHub Pages on main pushes touching docs/src/README (enable Settings → Pages → Source = GitHub Actions).
- pre-commit: new `sphinx-build` hook (`-W` warnings-as-errors, output `docs/build/`, triggered on `docs/` or `src/` changes); `docs/source/conf.py` no longer hacks `sys.path` (package installed by `uv sync`, build via `uv run`); skill template updated.
- All-English project rule (code, docstrings, comments, docs, CLI messages, statuses, commit messages); statuses renamed to `needs_review` / `unread` / `partial`, CLI `--threshold` / `--gray-threshold`.
- Docstrings required on the public Python API (Google convention; ruff `D` + `pydoclint` in lint); SCOPE.md and the `python-exemplaire` skill updated accordingly.
- D5: robust QR + multi-page + thresholds — `read_qr`: `detectAndDecodeMulti`, binarized/upscaled variants, page rotation deduced from the geometric position of the QR (upside-down/sideways pages read correctly); `omr_results.json` restructured as `{"scans": …, "copies": …}` with multi-page aggregation per `copy_id` (statuses `ok` / `needs_review` / `partial` / `unread`); CLI thresholds `--threshold` (0.35) and `--gray-threshold` (0.15): a choice is checked if fill >= threshold, `needs_review` if several checked or a gray trace, no answer (nothing above the gray threshold) = 0 pt without flag.
- Real validation: 40-question copy = 7 scanned pages (page 2 rotated 180°) → 7 scans `ok`, copy `ok`, 40/40 answers matching `answers.json`.
- D4: OMR geometry + bubbles — `detect_markers` (4 black squares via connected components, Otsu), `unwarp` (homography to A4 at 2 px/pt), `read_qr` (`cv2.QRCodeDetector`, `copy:XXXX|page:N`), `read_bubbles` (ink density of the inner disk, threshold 0.35, `needs_review` if != 1 checked), `process_scan` (pipeline + annotated image in `data/annotated/`), statuses `ok` / `needs_review` / `unread`. Template fix: right/bottom markers aligned at 0.7 cm from the page edge (the dx/dy were off by one marker width).
- Tests: `tests/test_omr.py` (synthetic markers, QR, checked/empty/ambiguous bubbles, homography-warped photo scan, `main()` end-to-end). Real validation: warped synthetic scan of `copy_0001` → status `ok`, answers recovered with fill 1.0 vs ~0.01; double check → `needs_review`; blank page → `unread`.
- D3: full generation — `plan_copies` (seeded shuffle of questions + choices, keys A/B/C, `answers` per copy, reproducible), `compile_copy` (build `data/build/XXXX/`: `main.typ` + `copy.json` + `qr-1..64.png`, `typst compile` → `data/copy_XXXX.pdf`), `export_positions` (`typst eval` on `#metadata` → `data/positions.json` indexed by `copy_id`, coordinates in pt + page size), `data/copy_XXXX.json` and `data/answers.json`. Validation: 3 copies seed 42, QR read `copy:0001|page:1`, positions landing at the center of the bubbles in the PNG render.
- Tests: `tests/test_gen.py` (reproducibility, shuffle validity, bank not mutated, compile + positions, `main()` end-to-end).
- D2: complete Typst template — `set page(background: …)` repeated on every page (4 alignment squares 1.2 cm + 3 cm QR at the top right, content `copy:XXXX|page:N` via `qr-{page}.png`), 4.5 cm top margin to avoid any QR/text overlap, `#metadata` (kind `question`/`bubble` with page/x/y) emitted for extraction via `typst eval`, non-breakable question blocks.
- Tests: `tests/test_template.py` compiles a 40-question copy (6 pages, 120 positioned bubbles) and checks the per-page QR decoding.
